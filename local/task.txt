VERIFIED SCHEMA FACTS (from published data_schema.json / Zenodo page)
- Top level: _id{$oid}, domain_name, url, source (source identifier), sourced_on{$date} (when loaded from source), evaluated_on{$date} (Zenodo page says "last collection attempt", schema file says "first processed by collector" -> treat as a processing timestamp only), dns, rdap, tls, ip_data, remarks.
- Malware family key CONFLICT: Zenodo page says "malware_type", schema file says "malware". Read both: r.get("malware_type") or r.get("malware"). Log which key exists. Only in malware.json; never null but may be "unknown".
- dns: A and AAAA are arrays or null. NS is an OBJECT keyed by nameserver name (value has related_ips[{ttl,value}]), or null. MX is an object keyed by MX name (priority, related_ips) or null. CNAME is null or {value, related_ips}. TXT array or null. SOA/zone_SOA null or object (primary_ns, resp_mailbox_dname, serial, refresh, retry, expire, min_ttl). ttls has per-type ints (0 if absent). remarks has has_dnskey, has_spf, has_dmarc, has_dkim, zone. dnssec has per-type enums.
- rdap: null or object with registration_date/expiration_date/last_changed_date (each null or {$date}), nameservers (array of strings), status[], dnssec bool, entities = object of arrays (registrar, abuse, registrant, admin, ...). Entity item structure is defined in $defs.rdapEntity of data_schema.json (not verified by me): read it at runtime.
- tls: null or {cipher, count, protocol, certificates[]}. Each certificate: common_name, organization, country (nullable), validity_start{$date} (may be {"$numberLong": "<ms>"}), validity_end{$date}, valid_len, extensions[{critical,name,value}], extension_count, is_root. THERE IS NO FINGERPRINT OR SERIAL. Zenodo says the first array element is the root; use the is_root flag, not position.
- ip_data: null or array of {ip, from_record in {A,AAAA,CNAME,MX,NS}, remarks{is_alive, average_rtt, *_evaluated_on}, rdap, geo (GeoLite2 City), asn (GeoLite2 ASN: number, organization, network - exact key names NOT verified)}. ip_data therefore includes IPs that came from NS and MX records, not only web-hosting IPs.
- remarks: dns_evaluated_on, rdap_evaluated_on, tls_evaluated_on, dns_had_no_ips.
- Any field may be missing (= null). Extra fields may exist. Dates may be strings or nested objects.
- Files are 1-6 GB: stream with ijson.items(f, "item", use_float=True) (avoids Decimal). Never json.load them.
